### ⚡ [1xveron](https://github.com/T58574/1xveron)
> **Ultra-fast, zero-latency desktop terminal multiplexer and AI orchestrator for Windows.**

Built in Rust (`tao` + `wry` + `portable-pty`) with an Apple-grade industrial aesthetic, zero AI-slop, and zero telemetry.

- **Portable Standalone Binary (~3.7 MB)**: Embedded frontend assets via `rust-embed` with zero runtime dependencies.
- **Deep ConPTY Teardown**: Recursive process tree termination (`taskkill /T /F`) guarantees zero zombie processes (`node`, `python`, `cargo`).
- **Dynamic 1–6 Grid & Splitters**: Absolute coordinate tracking for zero-lag resizing and drag-and-drop window swapping.
- **14 Built-In Themes**: Industrial palettes (Cybran Amber, Emerald Matrix, Cobalt Cyan) with live HEX/picker color calibration.
- **Antigravity AI & Worktrees**: Dedicated agent workspaces, "Needs Input" prompt detection, and isolated Git worktrees.
